# open-scion-tier

Cache tiers for the Scion version control system: scion-cache and scion-daemon.

A read cache in front of a server: `scion-cache` for one machine, `scion-daemon` for a site.

Part of [open-scion](https://github.com/bnsd55/open-scion), a version
control system for large monorepos. See the repository for the design
and the rest of the system.

```sh
cargo add open-scion-tier
```
