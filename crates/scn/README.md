# open-scion

Command-line client for the Scion version control system.

The `scn` binary: cat, ls, log, show, commit, land, checkout, blame,
diff, merge-base, is-ancestor, mount, bench.

Part of [open-scion](https://github.com/bnsd55/open-scion), a version
control system for large monorepos. See the repository for the design
and the rest of the system.

```sh
cargo install open-scion
```
