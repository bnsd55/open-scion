# open-scion-core

Object model and canonical byte format for the Scion version control system.

The frozen v1 format: blob, changeset and tree objects, canonical encoding, and the IDs that hash it.

Part of [open-scion](https://github.com/bnsd55/open-scion), a version
control system for large monorepos. See the repository for the design
and the rest of the system.

```sh
cargo add open-scion-core
```
