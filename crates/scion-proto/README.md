# open-scion-proto

gRPC API definitions for the Scion version control system.

The v1 service: blob upload, changesets, lands, reads, and the wire
types that clients and the server share.

Part of [openscion](https://github.com/bnsd55/openscion), a version
control system for large monorepos. See the repository for the design
and the rest of the system.

```sh
cargo add open-scion-proto
```
