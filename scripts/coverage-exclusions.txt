# The statement-coverage measure's exclusions: one filename regex per
# line, joined by the coverage job into cargo-llvm-cov's
# --ignore-filename-regex. A # starts a comment, on its own line or
# after the regex. The job fails when a pattern here matches no tracked
# file, so a vacuous exclusion cannot hide in this file.
#
# Today the file holds no patterns, for two reasons the measure makes
# true by construction:
#
# - The generated proto code (tonic_prost_build) builds into OUT_DIR
#   under target/, which the measure never counts.
# - The test seam of scion-server (the "test_support" module,
#   lib.rs's "the one test seam") sits behind the test-hooks feature,
#   and the measure runs the default features, so the seam does not
#   compile into the report. A regex cannot name part of lib.rs; if
#   the seam ever moves to its own file, its line goes here.
